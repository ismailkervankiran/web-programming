## Sprint 1 — HTML, Git ve Yayına Alma

`sprint1/` klasöründe yalnızca HTML ile yazılmış sayfalar (CSS ve JavaScript yok):

- `etkinlik-detay.html` — etkinlik detayı

- `etkinlik-guncelle.html` — etkinlik güncelleme formu
